# Sara's portfolio (SARA-OS)

A robot-themed portfolio site: a single `index.html` with no build step.

- Circuit board home page, draggable app windows, and a patch bay wiring skills to projects
- Dark and light mode
- Featured project: [Splanner](https://splanner.xo.je)

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
